# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Undecided. The first panel is a static HTML mockup; where the panel lives afterwards (local static file reading `exports/`, GEX Hub, or other) is an open decision.

## Users

Two jobs on the same panel, used daily for the previous day (D-1):

- **Result of the day:** management and finance follow sales, net, refunds and chargebacks per account and gateway.
- **Source check:** the data team confirms that API and lake match the web panel before trusting a number; it works through the diff and the divergent accounts.

## Product Purpose

Show, per gateway and day, the daily report every source produces (BuyGoods and PagAmerican; web panel, public API and canonical lake) in one contract of 12 fields per account, and how far API and lake are from the web panel. Success: in one look, know how the day went and whether the numbers can be trusted.

## Positioning

The same day, the same accounts and the same formula across three independent sources, with the web panel as the base and every divergence visible per account and field, at US$ 0.01 tolerance.

## Operating Context

- Generated by `make buygoods|pagamerican[-api|-lake]` and `make diff GATEWAY=...`, saved under `exports/<gateway>/<source>/AAAA/MM/` and `exports/<gateway>/diff/AAAA/MM/`.
- Day D: BuyGoods GMT-4; PagAmerican UTC (web/API by checkout day, lake by sale day).
- Accounts: BuyGoods per panel account (API and lake also list secondary accounts "… 2" absent from the panel login); PagAmerican per front product of the order.

## Capabilities and Constraints

- Report fields: `gross_sales`, `shipping_and_handling`, `commissions`, `refunds`, `chargebacks`, `commission_voids`, `taxes`, `net_sales`, `aov`, `epo`, `affiliate_epo`, plus `account_name`. All money in USD.
- Diff statuses: `igual`, `divergente`, `faltando_na_fonte`, `extra_na_fonte`; AI view (`schemas/diff_ai.schema.json`) and dashboard long format (`schemas/diff_dashboard.schema.json`).
- No Visitors, Conversion Rate or EPC: the API does not provide them, so no source carries them.
- Known differences, not errors: PagAmerican lake vs web around midnight checkouts; BuyGoods lake commission voids approximated from chargebacks.

## Brand Commitments

GEX design system (`gex-design-system` skill, `tokens.css`) is binding: dark theme default, navy top gradient with cyan glow, Geist and Geist Mono, Lucide icons, color carries meaning, Brazilian number format, pt-BR copy in Title Case labels, no emoji or exclamation.

## Evidence on Hand

Real generated reports for 2026-10-28 (BuyGoods web, API, lake) and 2026-10-29 (PagAmerican web, API, lake), plus their diffs, under `exports/` (gitignored). No other days exist yet; trends over time must not be fabricated as real.

## Product Principles

- Result first, trust right beside it: the number of the day never appears without its source agreement.
- The web panel is the base; other sources are measured against it, never averaged with it.
- Known differences are labelled as known, not shown as errors.
- Per account and per field, down to the cent.
